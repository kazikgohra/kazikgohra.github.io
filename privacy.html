Gmail Local Archive · wersja z 10 września 2026 r.

1. Aplikacja i jej właściciel

Gmail Local Archive jest osobistą aplikacją lokalną utrzymywaną przez użytkownika GitHub kazikgohra. Służy do wykonywania i przeglądania kopii własnej poczty na komputerze z Windows. Nie jest publiczną usługą przechowywania poczty. Adres pomocy dotyczący autoryzacji jest wskazany na ekranie zgody Google.

2. Odczytywane dane i cel ich wykorzystania

Po udzieleniu zgody OAuth program korzysta wyłącznie z zakresu https://www.googleapis.com/auth/gmail.readonly. Zakres ten technicznie pozwala czytać pocztę; program ogranicza wybór wiadomości do starszych niż dwa lata, pomijając Spam i Kosz.

Program odczytuje adres autoryzowanego konta, identyfikatory i daty wiadomości, nazwy etykiet, rozmiary oraz pełne wybrane wiadomości: nagłówki, nadawców, odbiorców, tematy, treść tekstową i HTML oraz załączniki. Informacje służą wyłącznie do utworzenia kopii, uniknięcia duplikatów, kontroli poprawności oraz lokalnego wyszukiwania i przeglądania.

Program nie usuwa wiadomości na Gmailu, nie zmienia etykiet, nie oznacza wiadomości jako przeczytanych i nie wysyła poczty. Przeglądarka lokalnego archiwum nie korzysta z Gmail API ani z tokenów Google. Nie przeszukuje zawartości załączników.

3. Przechowywanie i zabezpieczenia

Wiadomości EML, indeks CSV, bazy kontrolne i wyszukiwania, logi oraz raporty są zapisywane lokalnie w katalogu archiwum, domyślnie C:\Gmail_Archive. Indeksy mogą zawierać dane osobowe z wiadomości. Kopie załączników otwieranych przez użytkownika są zapisywane w lokalnym folderze tymczasowym; funkcja „Zapisz jako…” zapisuje kopię we wskazanym miejscu.

Program nie pobiera ani nie zapisuje hasła Google. Token odświeżania i dane klienta potrzebne do jego użycia są przechowywane lokalnie w pliku szyfrowanym przez Windows DPAPI, powiązanym z kontem Windows użytkownika. Pobrany ręcznie plik konfiguracji klienta OAuth JSON może pozostawać na dysku do chwili jego ręcznego usunięcia.

Połączenia z Google odbywają się przez HTTPS. Dostęp do folderów archiwum jest ograniczony uprawnieniami Windows. Same EML i indeksy nie są szyfrowane przez aplikację. Bezpieczeństwo danych zależy także od zabezpieczenia konta, dysku i kopii zapasowych użytkownika.

4. Udostępnianie i inne usługi

Aplikacja nie wysyła archiwum, treści maili, załączników ani tokenów na GitHub Pages, do autora, usług analitycznych, reklamowych ani systemów AI. Nie sprzedaje danych i nie wykorzystuje ich do reklam lub trenowania modeli. Dane uzyskane przez Google API są używane zgodnie z Google API Services User Data Policy, w tym zasadami ograniczonego wykorzystania danych (Limited Use).

Autoryzację i dostęp do źródłowej poczty zapewnia Google. Otwarcie załącznika przekazuje lokalną kopię do programu wybranego w Windows; dalsze działanie tego programu podlega jego własnym ustawieniom i zasadom. Ręczne udostępnianie plików lub synchronizowanie folderu przez użytkownika nie jest funkcją tego archiwizatora.

5. Okres przechowywania i usuwanie

Kopie wiadomości, indeksy i raporty są przechowywane do czasu ich usunięcia przez użytkownika. Aplikacja nie stosuje automatycznego terminu usuwania archiwum. Tymczasowe kopie otwieranych załączników starsze niż siedem dni są sprzątane podczas uruchamiania przeglądarki, o ile pliki nie są zablokowane.

Użytkownik może cofnąć zgodę w ustawieniach połączeń z aplikacjami w koncie Google i usunąć lokalny plik tokenu. Cofnięcie zgody zatrzymuje możliwość dalszego pobierania, ale nie usuwa już zapisanej kopii. Aby całkowicie usunąć lokalne dane, należy zakończyć program i usunąć archiwum, jego indeksy i kopie załączników oraz własne dodatkowe kopie zapasowe. Usunięcie kopii lokalnej nie usuwa wiadomości z Gmaila.

6. Publiczna strona informacyjna

Ta strona nie służy do logowania do Gmaila i nie ma dostępu do lokalnego archiwum. Nie zawiera dodanych przez autora reklam, narzędzi analitycznych ani formularza zbierającego dane. Hosting GitHub Pages może przetwarzać techniczne dane odwiedzin, takie jak adres IP, zgodnie z polityką prywatności GitHub.

7. Zmiany i kontakt

Zmiany sposobu wykorzystywania danych wymagają aktualizacji tego opisu i odpowiedniej informacji przed ich wdrożeniem; rozszerzenie dostępu wymaga nowej zgody. Autora identyfikuje profil kazikgohra. W publicznych zgłoszeniach nie należy umieszczać treści poczty, haseł, tokenów ani załączników.
